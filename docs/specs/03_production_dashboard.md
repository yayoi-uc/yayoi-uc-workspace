## 1. 概要

### 1.1 目的
全発注の進捗をリアルタイムで可視化し、納期遅延やステータス変更をSlackで自動通知する。
「今どの発注がどの段階にあるか」を一目で把握できるダッシュボード。

### 1.2 解決する課題
| 現状の課題 | システムで解決 |
|-----------|--------------|
| 発注状況がチャットやメールに散在 | ダッシュボードで一元管理 |
| 納期遅延に気づくのが遅い | 自動リマインド・アラート |
| ステータス更新を口頭で共有 | リアルタイム可視化 |
| メーカーへの催促を忘れる | Slackリマインド自動化 |

### 1.3 ユーザーストーリー
- **発注担当として**、全発注のステータスをカンバン形式で一覧したい
- **運営メンバーとして**、納期が近い/遅延している発注をすぐ把握したい
- **発注担当として**、ステータス変更時にSlackへ自動通知してほしい
- **運営メンバーとして**、週次で発注状況のサマリーをSlackに投稿してほしい

| カラム名 | 型 | NOT NULL | 説明 |

| status | VARCHAR(20) | YES | ステータス |

| created_by | UUID | FK | 作成者 |
| created_at | TIMESTAMP | YES | 作成日時 |

## 6. Slack連携仕様

### 6.1 通知一覧

| トリガー | タイミング | メッセージ例 |
|---------|----------|------------|
| ステータス変更 | 即時 | 「📦 リングA のステータスが [製造中] → [出荷済] に変更されました」 |
| 納期リマインド | 納期7日前 / 3日前 | 「⏰ リングA（XX工房）の納期まであと3日です（5/15）」 |
| 納期遅延アラート | 納期翌日 | 「🚨 リングA（XX工房）が納期を超過しています！（予定: 5/15）」 |
| 週次サマリー | 毎週月曜 9:00 | 下記参照 |

### 6.2 週次サマリーフォーマット

```
📊 *週次 生産管理サマリー* (2026/04/06 〜 04/12)

*ステータス別:*
• 発注準備: 2件
• 発注済: 3件
• 製造中: 5件
• 出荷済: 1件
• 入荷済: 2件

*⚠️ 要注意:*
• ネックレスB（YY製作所）- 納期まで7日
• ピアスC（ZZ工房）- 納期まで12日

*今週完了:*
• ブレスF（BB工房）- 検品完了 ✅
```

### 6.3 実装方式
- Slack Incoming Webhooksで通知送信
- 定期実行: cron（納期チェック: 毎日9:00 / 週次サマリー: 月曜9:00）
