## 1. 概要

### 1.1 目的
商品企画書・仕様書のテンプレートを標準化し、メーカーごとに最適なフォーマットでPDF出力する。
毎回ゼロから企画書を作る手間をなくし、品質を均一化する。

### 1.2 解決する課題
| 現状の課題 | システムで解決 |
|-----------|--------------|
| 企画書のフォーマットが毎回バラバラ | テンプレートで標準化 |
| メーカーごとに必要項目が違う | メーカー別テンプレート対応 |
| 画像・スペックの転記ミス | 商品企画DBから自動引用 |
| Word/Excelで手作業作成 | ワンクリックPDF出力 |

### 1.3 ユーザーストーリー
- **企画担当として**、商品企画DBの情報を元に、企画書を自動生成したい
- **企画担当として**、メーカーの要求に合わせたフォーマットで仕様書を出力したい
- **企画担当として**、過去の企画書を参考にしたいので、一覧で管理したい

## 4. データモデル

### 4.1 テーブル定義

#### proposal_templates（企画書テンプレート）
| カラム名 | 型 | NOT NULL | 説明 |
|---------|-----|----------|------|
| id | UUID | PK | テンプレートID |
| name | VARCHAR(200) | YES | テンプレート名 |
| description | TEXT | | 説明 |
| sections | JSONB | YES | セクション定義（後述） |
| default_for_supplier_id | UUID | FK | デフォルト適用メーカー |
| created_at | TIMESTAMP | YES | 作成日時 |
| updated_at | TIMESTAMP | YES | 更新日時 |

**sections JSONBの構造:**
```json
[
  {
    "section_name": "基本情報",
    "fields": [
      {"key": "product_name", "label": "商品名", "source": "auto", "type": "text"},
      {"key": "product_code", "label": "商品コード", "source": "auto", "type": "text"},
      {"key": "material", "label": "素材", "source": "auto", "type": "text"},
      {"key": "image", "label": "商品画像", "source": "auto", "type": "image"}
    ]
  },
  {
    "section_name": "発注情報",
    "fields": [
      {"key": "quantity", "label": "発注数", "source": "manual", "type": "number"},
      {"key": "size_options", "label": "サイズ展開", "source": "manual", "type": "text"},
      {"key": "delivery_date", "label": "希望納期", "source": "manual", "type": "date"}
    ]
  },
  {
    "section_name": "備考",
    "fields": [
      {"key": "notes", "label": "備考", "source": "manual", "type": "textarea"}
    ]
  }
]
```

#### proposals（企画書）
| カラム名 | 型 | NOT NULL | 説明 |
|---------|-----|----------|------|
| id | UUID | PK | 企画書ID |
| template_id | UUID | FK | 使用テンプレートID |
| product_id | UUID | FK | 対象商品ID |
| supplier_id | UUID | FK | 対象メーカーID |
| title | VARCHAR(300) | YES | 企画書タイトル |
| content | JSONB | YES | 入力済みデータ |
| pdf_url | VARCHAR(500) | | 生成PDF保存先URL |
| status | VARCHAR(20) | YES | 作成中/完成/送付済 |
| created_by | UUID | FK | 作成者 |
| created_at | TIMESTAMP | YES | 作成日時 |
| updated_at | TIMESTAMP | YES | 更新日時 |

## 6. PDF出力仕様

### 6.1 出力フォーマット
- A4縦、日本語フォント対応
- ヘッダー: Maison TOIロゴ + 作成日
- フッター: ページ番号
- 商品画像は自動リサイズ（最大幅50%）

### 6.2 技術実装
- WeasyPrint（HTML → PDF変換）
- HTMLテンプレートをJinja2で動的生成
- 日本語フォント: Noto Sans JP
