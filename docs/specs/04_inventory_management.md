## 1. 概要

### 1.1 目的
検品から在庫管理、OpenLogiへの出荷データ連携までを一貫して管理するシステム。
良品/不良品の記録、在庫数のリアルタイム把握、OpenLogi CSVの自動生成で倉庫オペレーションを効率化する。

### 1.2 解決する課題
| 現状の課題 | システムで解決 |
|-----------|--------------|
| 検品結果をスプレッドシートで管理 | 検品記録のDB化・写真添付 |
| 良品/不良品の内訳が曖昧 | 個別記録で正確に管理 |
| OpenLogiへのCSV作成が手動 | 自動生成・バリデーション付き |
| 在庫数の把握がリアルタイムでない | ダッシュボードで即時確認 |

### 1.3 ユーザーストーリー
- **検品担当として**、入荷した商品を検品し、良品/不良品を記録したい
- **在庫担当として**、現在の在庫状況（商品別・ロケーション別）を一目で確認したい
- **出荷担当として**、OpenLogiに送るCSVをワンクリックで生成したい
- **運営メンバーとして**、不良率の高い商品・メーカーを把握したい

## 6. OpenLogi CSV連携仕様

### 6.1 出力CSV種別

#### a) 商品マスタCSV
OpenLogiに商品を登録するためのCSV。

| CSVカラム | 説明 | マッピング元 |
|----------|------|------------|
| item_code | 商品コード | products.product_code |
| item_name | 商品名 | products.name |
| jan_code | JANコード | products.jan_code（要追加） |
| price | 販売価格 | products.selling_price |
| weight | 重量(g) | products.weight（要追加） |
| length | 縦(cm) | products.length |
| width | 横(cm) | products.width |
| height | 高さ(cm) | products.height |

#### b) 入荷予定CSV
OpenLogiへ入荷予定を通知するためのCSV。

| CSVカラム | 説明 | マッピング元 |
|----------|------|------------|
| item_code | 商品コード | products.product_code |
| quantity | 入荷予定数 | inspections.good_quantity |
| scheduled_date | 入荷予定日 | orders.expected_delivery |
| warehouse_code | 倉庫コード | 設定値 |

### 6.2 バリデーション
CSV出力前に以下をチェック:
- 必須項目が全て埋まっているか
- 商品コードが重複していないか
- 数量が0以上か
- エラーがあればプレビュー画面で警告表示
