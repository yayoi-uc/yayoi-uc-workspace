## 8. リスク＆注意事項

| リスク | 対策 |
|--------|------|
| アニバーサリーサンプルが間に合わない | **5/12までに必ず生産発注**。工房に納期確認を5月上旬に実施 |
| 修正サンプルのリードタイムが足りない | 到着直後（6/16）に確認→即修正指示。予備日を確保 |
| インスタライブの通信環境 | 事前に現地回線テスト。バックアップとしてホテルWi-Fi＋モバイル回線の二重化 |
| 資材・ノベルティの品質ばらつき | 買付リストに品質基準を明記。サンプル確認→本発注のフローを徹底 |
| 体調管理（暑さ・食事） | 6月はモンスーン前で酷暑。水分補給・休息スケジュールを確保 |
